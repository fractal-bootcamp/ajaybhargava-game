# Game Repository

Per the [assignment](https://docs.google.com/document/d/1WFllqnmhnDbdjO6qw19XHHcWAC97rhAiEx20Nz7_ksI/edit?tab=t.0#heading=h.xprnecc3op0m) this is a game of tic-tac-toe.

## Tech Stack

- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)

## Setup

```bash
cd frontend
bun install
bun run dev
```
